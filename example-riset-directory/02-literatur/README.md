# 02-literatur

Folder ini berisi seluruh referensi ilmiah yang digunakan sebagai landasan teoritis dalam penelitian mengenai **prediksi penyakit menggunakan machine learning pada dataset medis terbatas dengan fokus pada overfitting dan generalisasi model**.

Literatur pada folder ini digunakan untuk mendukung penyusunan latar belakang penelitian, tinjauan pustaka, metodologi, serta pembahasan hasil eksperimen pada Tahap 5.

## Folder Paper

Folder `paper/` berisi kumpulan artikel ilmiah yang dikelompokkan berdasarkan topik penelitian.

Kategori referensi meliputi:

- `machine-learning/` — konsep dasar machine learning dan algoritma klasifikasi.
- `medical-dataset/` — penelitian mengenai prediksi penyakit menggunakan dataset medis.
- `overfitting/` — penelitian mengenai penyebab dan penanganan overfitting.
- `generalization/` — penelitian mengenai kemampuan generalisasi model.
- `cross-validation/` — metode validasi model pada dataset terbatas.
- `feature-selection/` — teknik seleksi fitur untuk meningkatkan performa model.
- `evaluation-metrics/` — metrik evaluasi klasifikasi seperti Accuracy, Precision, Recall, F1-Score, dan ROC-AUC.
