# 01-proposal

Folder ini berisi seluruh dokumen proposal penelitian yang menjadi dasar pelaksanaan penelitian.

Proposal disusun pada tahap awal penelitian untuk menjelaskan latar belakang, rumusan masalah, tujuan, metodologi, kontribusi penelitian, serta rencana pelaksanaan penelitian mengenai pengembangan model machine learning untuk prediksi penyakit pada dataset medis terbatas dengan fokus pada permasalahan overfitting dan kemampuan generalisasi model.

Seluruh isi proposal menjadi acuan pelaksanaan Tahap 1 hingga Tahap 5.

## Dokumen Proposal

Proposal penelitian memuat penjelasan mengenai seluruh aspek penelitian, meliputi:

- Fenomena overfitting pada dataset medis berukuran terbatas.
- Pentingnya kemampuan generalisasi model machine learning.
- Pemanfaatan teknik regularisasi dan validasi model.
- Pemilihan algoritma machine learning yang digunakan.
- Pemilihan dataset medis.
- Rencana preprocessing data.
- Rencana evaluasi model.
- Roadmap penelitian dari Tahap 1 hingga Tahap 5.

Proposal ini menjadi acuan utama selama penelitian berlangsung.
