# 00-admin

Folder ini berisi seluruh dokumen administratif yang mendukung pelaksanaan penelitian, mulai dari perencanaan kegiatan, pencatatan progres, hingga dokumentasi pelaksanaan penelitian.

Dokumen pada folder ini digunakan sebagai pengelolaan internal penelitian sehingga perkembangan setiap tahap dapat ditelusuri secara sistematis.

---

## Struktur Folder

```text
00-admin/
├── README.md
├── timeline-penelitian.md
├── log-penelitian.md
├── checklist-penelitian.md
└── catatan-pembimbing.md
```

---

## Isi yang Diharapkan

Folder ini mencakup berbagai dokumen administrasi penelitian, antara lain:

- Jadwal pelaksanaan penelitian.
- Log aktivitas penelitian.
- Checklist penyelesaian setiap tahapan penelitian.
- Catatan hasil bimbingan.
- Riwayat revisi penelitian.
- Dokumentasi progres penelitian.
- Catatan kendala selama penelitian.

---

## Timeline Penelitian

Pelaksanaan penelitian dibagi menjadi lima tahapan utama.

| Tahap | Kegiatan |
|--------|----------|
| Tahap 1 | Studi literatur, identifikasi masalah, perancangan metodologi penelitian |
| Tahap 2 | Implementasi preprocessing data dan pengembangan model machine learning |
| Tahap 3 | Pelaksanaan eksperimen dan proses pelatihan model |
| Tahap 4 | Analisis hasil eksperimen, evaluasi model, dan visualisasi hasil |
| Tahap 5 | Penyusunan proposal, laporan penelitian, dan naskah publikasi ilmiah |

---

## Log Pelaksanaan Penelitian

Folder ini digunakan untuk mencatat seluruh aktivitas penelitian, misalnya:

- Studi literatur mengenai prediksi penyakit menggunakan machine learning.
- Pengumpulan dataset medis.
- Proses preprocessing dataset.
- Pengembangan model machine learning.
- Pelaksanaan training model.
- Hyperparameter tuning.
- Evaluasi performa model.
- Analisis overfitting dan generalisasi model.
- Penyusunan laporan penelitian.
- Penyusunan artikel ilmiah.

---

## Checklist Penelitian

Checklist digunakan untuk memantau penyelesaian setiap tahapan penelitian.

Contoh checklist:

- Studi literatur selesai.
- Dataset berhasil dikumpulkan.
- Dataset selesai diproses.
- Model machine learning berhasil diimplementasikan.
- Eksperimen selesai dijalankan.
- Evaluasi model selesai.
- Analisis overfitting selesai.
- Visualisasi hasil selesai.
- Proposal penelitian selesai.
- Laporan penelitian selesai.
- Naskah jurnal selesai.

---

## Catatan Pembimbing

Folder ini dapat digunakan untuk menyimpan:

- Masukan terhadap proposal.
