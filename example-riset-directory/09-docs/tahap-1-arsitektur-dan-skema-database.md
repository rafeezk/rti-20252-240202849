# Tahap 1 — Perancangan Penelitian

Status: Selesai

## Tujuan

Merancang keseluruhan penelitian machine learning mulai dari pemilihan dataset hingga desain eksperimen.

## Deliverable

- Studi literatur
- Pemilihan dataset
- Analisis dataset
- Desain preprocessing
- Desain eksperimen
- Penentuan model machine learning
- Penentuan metrik evaluasi

## Dataset

Dataset yang digunakan merupakan Heart Disease Dataset.

Analisis meliputi:

- jumlah data
- jumlah fitur
- distribusi kelas
- missing value
- outlier
- imbalance data

## Data Preprocessing

- Missing Value Handling
- Feature Scaling
- Label Encoding
- Train-Test Split

## Model yang Digunakan

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine
- K-Nearest Neighbor

## Teknik Pencegahan Overfitting

- Cross Validation
- Hyperparameter Tuning
- Regularization
- Feature Selection

## Metrik Evaluasi

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

## Status

Tahap perancangan penelitian telah selesai dan menjadi dasar implementasi pada Tahap 2.
